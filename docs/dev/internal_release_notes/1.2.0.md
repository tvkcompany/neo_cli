## Changes 🛠️

### Template Builder

- Updated `template_builder.dart` to escape `${}` sequences when reading template files: `content.replaceAll(r'${', r'\${')` to prevent Dart from trying to interpolate them in const context

### Router Architecture Implementation

- Added Riverpod provider for router using `@Riverpod` annotation with `keepAlive: true`
- Updated router imports and usage in `main.dart` to use `routerProvider`

### Sidebar Template Implementation

- Removed `MyObserver` class from sidebar template router file
- Removed unused imports (`flutter_hooks`, `hooks_riverpod` from router observer) from sidebar template files
